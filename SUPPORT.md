# Support

For help with `devrunner`:

1. Check `README.md` for install, usage, configuration, and exit-code details.
2. Search existing issues for your ecosystem or package manager.
3. Open a bug report with the issue template if behavior looks wrong.
4. Open a feature request if you want a new ecosystem, runner, or workflow supported.

Please include `devrunner --version`, your operating system, the relevant manifest or lockfiles, and the exact command you ran.
