# Code of Conduct

We want `devrunner` to be a welcoming, practical, and respectful open source project.

## Expected behavior

- Be kind, patient, and constructive.
- Assume good intent, especially with new contributors.
- Focus critique on code, design, tests, and user impact.
- Respect different experience levels, backgrounds, and communication styles.
- Help keep issues and pull requests actionable.

## Unacceptable behavior

- Harassment, intimidation, threats, or personal attacks.
- Discriminatory language or behavior.
- Trolling, sustained disruption, or bad-faith arguments.
- Publishing private information without permission.
- Any conduct that makes the project unsafe or unwelcoming.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; reject contributions; or block participants when needed to protect the community. If you see a problem, report it privately to the maintainers through the repository owner's GitHub profile or by opening a minimal issue asking for a private contact path.
